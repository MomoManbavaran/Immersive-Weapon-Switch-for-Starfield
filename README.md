# Immersive Weapon Switching for Starfield

SFSE plugin that, on weapon switch (either using hotkeys or the favorite menu) **automatically holsters your currently equipped weapon before drawing the newly selected one**.

Works in **first** and **third person**.

Works with modded weapons.

Works while reloading, spriting, crouching, etc.


## Requirements

- [Starfield Script Extender (SFSE)](https://www.nexusmods.com/starfield/mods/106)

## Installation

1. Install SFSE.
2. Copy `ImmersiveWeaponSwitching.dll` to `Data/SFSE/Plugins/`  
   (or install with your preferred mod manager (recommended)).
3. Launch the game via SFSE.
